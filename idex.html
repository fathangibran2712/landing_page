Kenapa pakai GitPush?

Belajar Git tidak harus terasa rumit. GitPush menyederhanakan konsep penting agar kamu bisa fokus menulis kode dan berlatih.

📦

Staging Area

Pahami cara memilih perubahan yang ingin dimasukkan ke commit sebelum kode dikirim ke repository.

🧾

Commit History

Simpan riwayat perubahan proyek dengan pesan commit yang jelas, rapi, dan mudah dipahami.

🚀

Push ke Remote

Kirim pekerjaan lokal kamu ke GitHub agar kode tersimpan aman dan bisa diakses dari mana saja.

Cara kerja dalam 3 langkah

Ini alur dasar yang akan sering kamu gunakan saat mengerjakan proyek dengan Git.

1

Tambahkan perubahan

Gunakan perintah ini untuk memasukkan file yang telah kamu ubah ke staging area.

git add .
2

Buat commit

Simpan snapshot perubahan dengan pesan yang menjelaskan apa yang kamu kerjakan.

git commit -m "feat: tambah landing page"
3

Push ke GitHub

Kirim commit dari komputer lokal kamu ke branch main di repository remote.

git push origin main

Siap push kode pertamamu?

Buka terminal, jalankan tiga perintah di atas, dan lihat proyek landing page kamu tampil di GitHub.
